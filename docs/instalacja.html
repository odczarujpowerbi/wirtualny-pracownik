Instalacja i obsługa

Jak zainstalować i uruchomić narzędzie na nowej maszynie, co wpisać w dostępy i gdzie klikać. Po ludzku, w punktach.

0 Czego potrzebujesz

  • Maszyna: Windows Server 2022 albo Windows 11 (dedykowana, włączona 24/7, stały internet).
  • Konto Microsoft 365 Business Standard (do aktywacji Office i pracy w chmurze).
  • Subskrypcja Claude (do logowania w Claude Code) oraz klucze: Projectly, opcjonalnie inne.
  • Uprawnienia administratora na maszynie (część instalacji tego wymaga).

1 Instalacja środowiska

Instalacja jest bezobsługowa — uruchamiasz i możesz wrócić później. Nie zatrzymuje się na logowaniach.

  1. Pobierz projekt

    Maszyna zupełnie pusta (bez repo, bez gita)? Otwórz PowerShell jako administrator i wklej jedną linię:

    $s="$env:TEMP\postaw.ps1"; irm https://raw.githubusercontent.com/odczarujpowerbi/wirtualny-pracownik/main/instalacja/skrypty/postaw-od-zera.ps1 -OutFile $s; powershell -ExecutionPolicy Bypass -File $s

    Jeśli repo już jest na maszynie — przejdź do kroku 2.

  2. Uruchom instalator

    Wejdź do folderu instalacja, kliknij prawym na Przygotuj-srodowisko.bat → Uruchom jako administrator. Zainstaluje po kolei: Git, Python, Node.js, Claude Code, VS Code, Office, aplikacje (Power BI, Teams, Outlook, Chrome), zależności, autostart 24/7, test i raport.

    Każdy krok sprawdza, czy dana rzecz już jest — ponowne uruchomienie jest szybkie.

2 Wpisz dostępy (secrets)

Sekrety nigdy nie trafiają do repozytorium. Leżą lokalnie w app/secrets/.

Plik app/secrets/.env — klucze

KluczCo wpisać / skąd
ANTHROPIC_API_KEYKlucz API Anthropic (opcjonalny, jeśli logujesz się subskrypcją przez claude login). Fallback głównego modelu.
PROJECTLY_API_KEY / PROJECTLY_BASE_URLKlucz i adres API Projectly. Bez klucza agent działa w trybie mock (dane lokalne).
MS_GRAPH_CLIENT_ID / SECRET / TENANT_ID / MAILBOXOpcjonalnie — realna wysyłka maila przez Microsoft Graph (rejestracja aplikacji w Azure AD).
OLLAMA_HOST / OLLAMA_VISION_MODEL / OLLAMA_TEXT_MODELOpcjonalnie — modele lokalne (domyślnie localhost:11434).
CLAUDE_CODE_CALL_PROXY_USD / daily_cost_limit_usd.txtOpcjonalnie — dostrojenie bezpiecznika kosztu (patrz Modele i koszty).

Folder app/secrets/mcp/*.json — integracje MCP

Po jednym pliku na integrację MCP: projectly.json, zoho_crm.json, zanfia_courses.json. Uzupełnij adres serwera/token wg konkretnej konfiguracji MCP.

3 Uruchom agenta

Agent startuje sam po zalogowaniu (autostart ustawia instalator). Ręcznie:

cd app
python job_scheduler.py        # pętla 24/7 (pobiera zadania, klasyfikuje, waliduje)
python dashboard.py            # podgląd: http://127.0.0.1:8787/

4 Zaloguj się na konta

Osobny, szybki krok — po instalacji. instalacja/Zaloguj.bat przewodzi po kolei.

KontoPo co
Claude Code (claude w terminalu)Napęd głównego modelu — konieczne, inaczej bramka jakości degraduje (fail-closed).
VS Code — chmurowe + personalneKodowanie z agentem, Settings Sync, GitHub.
Microsoft 365 + aktywacja OfficeMail/SharePoint/OneDrive.
Gmail / Google, Meta Business, GitHubPraca przez interfejs, gdy nie da się przez API.

5 Codzienne użycie

  • Nowy kod z GitHub: dwuklik aktualizuj-repo.bat.
  • Podgląd pracy: python app/dashboard.py → http://127.0.0.1:8787/ — patrz Panel operatora.
  • Zatrzymanie: przycisk Stop w dashboardzie (albo Pauza — bez utraty stanu).
  • Nowe zadanie bez Projectly: formularz „Dodaj zadanie" albo dopisz linię do app/inbox/zadania.txt.

6 Gdy coś nie działa

ObjawCo zrobić
Aplikacje / Terminal się nie zainstalowałyNa Windows Server często brak winget. Instalator próbuje go doinstalować.
claude nie działa w terminaluDodaj C:\Users\<user>\.local\bin do PATH i otwórz nowy terminal.
Bramka jakości wszystko eskalujeSprawdź, czy jesteś zalogowany w claude — bez modelu odbiór biznesowy nie działa (celowo, fail-closed).
Pobieranie ze źródła internetowego zwraca odmowęSprawdź, czy host jest na allowliście: app/config/tool_contracts.yaml → fetch_url.allowed_domains.
